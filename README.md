# Nature's Pride Nurseries and Landscaping

A responsive one-page website for GitHub Pages.

## Files
- `index.html` — complete website
- `assets/nature-pride-logo.jpg` — supplied business logo

## Publish with GitHub Pages
1. Create a GitHub repository named `natures-pride-website`.
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will provide the published website address.
